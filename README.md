## Name
lilavatarutilsを簡単に開けることの可能にすることから  
"Openlilavatarutils"  
としました。  

## Concept
毎回Tools > lilavatarutilsを押してGameObjectをDDするのが面倒だったので、  
より簡単に開けるようにするために作られました。
それ以上でもそれ以下でもありません。  

## Overview
lilavatarutilsを導入したUnity2022.3.22f1に導入してご利用下さい。
lilavatarutilsに冠詞手は、以下のリンクからVCCに追加して導入するのをおすすめします。
[lilxyzwを追加](vcc://vpm/addRepo?url=https://lilxyzw.github.io/vpm-repos/vpm.json)

## Features
簡単にlilavatarutilsを開けます。

## How to use
開きたいGameObject上で右クリックして  
"Open lilavatarutils"  
を押してください。  
想定ではModularAvatarメニューの真下あたりに出てきます。
